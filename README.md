# PACHINKO LAB

ブラウザだけで動く日本語パチンコ確率シミュレーター。サンプルスペックはすべて架空です。

## 機能

- 左打ち：大当たり確率、チャージ確率・出玉・突入率、右打ち突入率
- ST：右打ち当たり確率、ST回数、残保留、当たり時リセット
- 転落：当たり確率、転落確率（大当たりを優先し、ハズレ時に転落抽選）
- 小当たりラッシュ：当たり確率、小当たり確率・出玉、当たり後の継続／終了
- 初当たり・右打ちの出玉振り分け（1〜20行、合計100%）
- 消費玉、手動・連続・自動抽選（1・10・100・1,000回転/秒）、履歴CSV、差玉グラフ、設定の端末内保存
- 再現可能なシード付き一括試行、差玉の分位点、連チャン分布、継続率の理論値

## ローカル実行

Node.js 22以降とPython 3を使用。追加のパッケージインストールは不要です。

```sh
npm run dev
# http://127.0.0.1:4173
npm test
npm run build
```

`dist/` が静的配信ファイルです。Google Fontsが読み込めない場合は端末のフォントで動作します。

## 計算モデル

通常時の大当たりとチャージは排他的なカテゴリ抽選です。突入率と初当たり出玉振り分けは独立です。出玉は払出総数ではなく獲得玉数を指定し、回転に応じた消費玉を別途差し引きます。小数で累積し、表示時に丸めます。STの残保留はSTと同じ当たり確率で扱います。ST・転落の終了後に時短はありません。小当たりは大当たりハズレ時に条件付きで抽選し、当たり時の終了振り分けでRUSHを終えます。

継続振り分け率を k、当たり確率を p、転落確率を f とすると、1周期の当たり獲得率は ST: `1-(1-p)^(ST+残保留)`、転落: `p/[p+(1-p)f]`、小当たり: `1`。画面の理論継続率は当たり獲得率×kです。

一括試行は通常上限まで、または最初の大当たり／チャージ経由の突入まで回し、右打ちに入れば終了まで回します。右打ち20万回転に達した試行は除外。全試行の合計が1,000万回転に達した場合は終了済み試行だけを集計します。自動抽選は継続して左右のモードを進めます。「100回転」「当たりまで」は大当たりまたはモード終了・チャージ突入で停止します。

実機の入賞構造、開放時間、時短・LT、特図や保留固有の確率、出玉と突入の相関は未対応です。実際の性能や遊技結果を保証するものではありません。
